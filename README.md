# 王树东 · 个人简历

静态 HTML/CSS/JS 简历，兼容 GitHub Pages，无需安装前端依赖。

- `index.html`：简历内容与语义结构。
- `assets/resume.css`：桌面、手机及 A4 打印样式。
- `assets/resume.js`：调用浏览器打印，可在打印窗口选择保存为 PDF。
- `_config.yml`：GitHub Pages 配置。

本地预览：在仓库目录运行 `python -m http.server 8765`，访问 http://localhost:8765。
